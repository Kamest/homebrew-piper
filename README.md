# Homebrew tap for Piper

```sh
brew install --cask kamest/piper/piper
```

Installs the [Piper](https://github.com/Kamest/Piper) desktop app. The cask is generated and updated by
the Piper release workflow from each published `desktop-v*` release; do not edit it by hand.

The builds are not signed by Apple yet: on first launch open System Settings › Privacy & Security and press
Open Anyway. See the [code signing policy](https://github.com/Kamest/Piper/blob/main/docs/CODE_SIGNING.md).
